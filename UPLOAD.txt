ごじょリアンAR 青・地面配置版（フォルダなし）

1. ZIPを解凍します。
2. GitHubの Add file → Upload files を開きます。
3. このフォルダの中のファイルをすべて選び、まとめてドラッグします。
   ZIP自体や外側のフォルダではなく、index.htmlなど中身を入れてください。
4. Commit changesで保存します。
5. Settings → Pages → Sourceで Deploy from a branch を選択します。
   Branchはmain（または実際のブランチ）、Folderは / (root) を選んでSaveします。
6. 公開が完了したら、スマホのSafari／対応AndroidのChromeで開きます。

一度この設定にすれば、次回からファイルを上書きするだけです。
Actionsのpathを編集したり、フォルダをCreateしたりする必要はありません。

以前の版でActionsを設定したリポジトリも、手順5でブランチ公開に切り替えてください。
従来のdistフォルダ内のファイルを上書きするのではなく、リポジトリの一番上に今回のファイルを追加してください。
複数の古い公開ワークフローが残っている場合は、Actionsから古いワークフローをDisable workflowにすると重複公開を防げます。
新規リポジトリでも同じ手順で公開できます。

全ファイルを同じ場所に置く構成です。ファイル名は変更しないでください。
コードはJS/CSS/HTMLを直接編集できます。ビルド不要、APIキー不要です。
モデルは04_white 1.glb、演出は水色・ピンクの星、UIは青系です。
内カメ最大3人、写真保存、外カメの地面への固定・瞬き・足元の影を引き継いでいます。
iPhoneでは標準AR画面のシャッターをタップして写真、長押しで動画を撮影します。
内カメとAndroid WebXRの動画録画は未実装です。実機での最終確認は別途必要です。
